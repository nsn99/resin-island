ISOLE - интерактивный остров

Готовая версия: portable/Interactive_Island.html
Откройте этот файл в браузере. Установка и интернет не нужны.
Курсор над водой: рябь. Перетаскивание: вращение. Колесо: масштаб.
Пробел: пауза. R: сброс. На слабом компьютере выберите Lite.

Автономный HTML работает на WebGL 2.
Отдельно приложены исходники Vite + React + R3F 9 + Drei + Leva.
Полная сборка React-проекта не проверена: npm был недоступен.
Для неё: npm install, затем npm run dev. Нужен Node.js 20.19+.

Это рабочий прототип. Фотореалистичное совпадение с референсом не достигнуто.
60/30 FPS на реальных устройствах не проверены.
Подробности и результаты проверок: README.md, TEST_REPORT.json, tests/.
